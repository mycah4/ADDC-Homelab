# Active Directory Home Lab

## Overview

I built a Windows Server 2022 Active Directory environment
to practice enterprise IT administration and cybersecurity.

## Technologies

- Windows Server 2022
- Windows 10 Pro
- Active Directory Domain Services
- DNS
- Group Policy
- Oracle Virtualbox Workstation
- PowerShell

## Lab Architecture

- Windows Server 2022
  - Domain Controller
  - DNS Server
  - Active Directory
- Windows 10 Pro
  - Domain-joined workstation

## Objectives

- Deploy Active Directory Domain Services
- Create and manage users
- Create security groups
- Join Windows clients to the domain
- Configure Group Policy
- Manage permissions
- Configure DNS
- Practice basic security controls

## Projects

### Active Directory Domain Controller

Configured Windows Server 2022 as a domain controller and
created the lab domain.

### User and Group Management

Created organizational units, users, and security groups
to simulate an organizational environment.

### Group Policy

Created Group Policy Objects to manage Windows client
settings and security configurations.

### Windows Client

Joined a Windows 10 Pro workstation to the domain and
tested authentication using domain accounts.

- Domain authentication
- Group Policy
- DNS
- User and group management
- Windows security configuration
- Troubleshooting domain connectivity
